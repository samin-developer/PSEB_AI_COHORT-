# Assignment 01: Student Manager

This is my first assignment in the **PSEB AI Cohort**. The task was to create a simple Python program that stores student records, displays students scoring above 50, and finds the top scorer.

## Features

- Defines a `Student` class with name and score.
- Stores three students in a list.
- Uses a loop to display students scoring above 50.
- Finds the highest-scoring student using the `top_scorer()` function.

## Concepts Practiced

Python classes, objects, lists, loops, conditional statements, and functions.

## Output

Students scoring above 50: Ali (75) and Samin (92).

Top scorer: Samin with 92 marks.


## Assignment 02 – Python, SQL & Pytest

In the second assignment of the PSEB AI Cohort, I worked on three tasks covering API integration, SQL database operations, and Python testing using Pytest. The main purpose of this assignment was to practice working with real-world data, databases, and automated testing.

### Task 1: GitHub API Integration
- Used the GitHub API to fetch information about three GitHub users.
- Retrieved their usernames and public repository counts.
- Checked the API response status code (200) before accessing the data.

### Task 2: SQL Library Database
- Created a library database with a books table.
- Added 8 books with their IDs, titles, authors, and prices.
- Used SQL queries to filter books priced above 500.
- Sorted books by price in descending order.
- Counted the total books written by each author using `GROUP BY`.
- Updated a book's price using `UPDATE` and `WHERE`.

### Task 3: Python Testing with Pytest
- Created an `is_adult(age)` function to check whether a person is 18 or older.
- Used `ValueError` to handle negative age inputs.
- Wrote three test cases for ages 17, 18, and -1.
- Used Pytest to verify the expected results.

### Technologies Used
- Python
- GitHub REST API
- SQL
- Pytest
- Git & GitHub

### Learning Outcomes
Through this assignment, I practiced fetching data from APIs, managing databases using SQL queries, and writing automated tests in Python. It helped me improve my understanding of backend development fundamentals and testing.
